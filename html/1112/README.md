# 시맨틱태그

## <header>
- 탐색에 도움을 줍니다.
- 회사명, 로고, 제목 등이 들어갑니다.

## <nav>
- 브래드크럼같이 따라들어가는 경로도 nav에 입력해줍니다.

## <article>
- 독립적인 기능을 수행합니다.
- 페이지의 중심 내용 영역을 나타냅니다.
- 이 영역을 제거해도 페이지는 정상적으로 돌아갑니다.
- ex : 뉴스의 각 문서 / 블로그 게시글 하나 하나 입니다.
- 위젯에서 많이 사용됩니다. ex : 날씨/위치정보, 증권위젯...
- 제목 요소를 자식으로 포함하여야 합니다.
- 다른 웹페이지에 넣어도 상관 없을 정도로 독립적입니다.

## <section>

- 주제별 구역을 나눌 때 사용합니다.
- 웹페이지의 앞뒤 문맥이 연결성이 필요할 때엔 section을 사용합니다.

## <aside>

- 독립적인 콘텐츠 블록입니다.
- 보조적인 정보 영역을 나타냅니다.
- 광고, 배너, 사이드바로 사용합니다.
- 메인과 같은 구역에 쓰일 시 영역을 구분해줍니다.

## <hr>

- 문단 안에서 주제가 변경되었을 때 사용합니다.
- p태그 내에서는 사용하지 않습니다.
- 일반적으로 자주 사용되진 않으나 보통 기사나 블로그에서 사용됩니다.
